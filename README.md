# محول ودمج PDF — Android

تطبيق Android يغلّف مشروع `image-to-pdf` الموجود على GitHub داخل WebView، مع دعم اختيار الصور وملفات PDF من الهاتف وحفظ ملفات PDF الناتجة في مجلد Downloads.

## البناء

افتح المجلد في Android Studio ثم اختر **Build > Build APK(s)**.

- Application ID: `com.sajfat19.image2pdf`
- Min SDK: 23
- Target SDK: 35
- الصفحة المستخدمة: https://sajfat19-prog.github.io/image-to-pdf/
